 # Diwali Sales Analysis
This repository contains a data analysis project on Diwali sales trends, exploring customer purchasing behavior, product categories, and sales performance during the festive season. The project uses Python (Pandas, NumPy, Matplotlib, Seaborn) to analyze and visualize sales data.

## 🔍 Key Insights
Top-selling products during Diwali

Customer demographics (age, gender, location)

Revenue trends across different states

Impact of discounts & offers on sales

Customer purchasing patterns (orders, spending habits)

## 🚀 Features
✅ Data Cleaning & Preprocessing (handling missing values, outliers)

✅ Exploratory Data Analysis (EDA) with Pandas & NumPy

✅ Interactive Visualizations (Matplotlib, Seaborn, Plotly)

✅ Sales Forecasting (optional ML models)

✅ Jupyter Notebook & Python Scripts for easy execution

## 🛠️ Technologies Used
Python (Pandas, NumPy, Matplotlib, Seaborn)

Jupyter Notebook (for interactive analysis)

Plotly (for interactive charts)

Excel/CSV (data source)
